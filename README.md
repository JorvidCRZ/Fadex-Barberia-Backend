# Aplicacion-Barberia-Backend-DWI

Backend de la aplicación web para la gestión integral de una barbería.

Este proyecto corresponde a la parte del servidor de **DWI**, encargada de proporcionar las APIs y la lógica de negocio necesaria para gestionar las funcionalidades del sistema de barbería.

## Tecnologías

- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- JWT
- Flyway

## Descripción

El backend proporciona los servicios REST necesarios para la comunicación con el frontend, gestionando la información, autenticación, autorización, operaciones de negocio y persistencia de datos de la aplicación.
